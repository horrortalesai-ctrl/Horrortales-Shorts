# Cómo utilizar HorrorTales desde un chat de Codex

Abre esta carpeta como proyecto en Codex y escribe una de estas órdenes. No hace falta pegar las instrucciones ni los ejemplos: Codex los leerá desde el repositorio.

## Buscar casos

> Realiza la actualización semanal de HorrorTales. Busca 15 casos reales y variados con footage abundante, verifica que cada caso tenga nombre identificable y guarda el informe.

> Busca 10 historias de supervivencia y catástrofes grabadas en vídeo. Evita repetir casos del dashboard.

## Investigar

> Investiga a fondo el caso de Lars Mittank. Comprueba la cronología, separa hechos y teorías, localiza vídeos y fotografías y guarda el expediente.

> Investiga el caso número 4 del último informe semanal y dime si merece un guion.

## Crear un guion

> Crea el guion de Brian Shaffer siguiendo el estilo HorrorTales. Investiga automáticamente lo que falte, elige la duración adecuada entre 2 y 8 minutos y guárdalo como borrador.

> Reescribe este guion porque pierde tensión después del primer minuto. Conserva únicamente hechos verificables.

## Actualizar el dashboard

> Añade al dashboard los casos investigados que superen el mínimo editorial y genera de nuevo la versión que se abre con doble clic.

## Terminar una sesión

> Valida todos los archivos, resume lo que has cambiado y deja el repositorio preparado para subir a GitHub.

## Flujo recomendado para los dos socios

1. Descargar o actualizar el repositorio desde GitHub.
2. Abrir la carpeta en Codex.
3. Ejecutar una de las órdenes anteriores.
4. Revisar el informe, las fuentes y el guion.
5. Pedir a Codex que prepare los cambios para GitHub.

Sin una API, el botón del dashboard prepara la petición, pero la investigación y el guion se realizan en el chat de Codex.
